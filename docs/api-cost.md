# 벤더 API 비용 메모 (1주차 D3, 2026-10-29)

플랜 1주차 D3 5번 "문서 유형별 평균 길이 → API 토큰 추정 → (사용자) 예산 상한"의 산출물이다. 2주차 D1에 표본 100건으로 실제 비용을 다시 잰다. 벤더는 아직 정하지 않았으므로 대표 벤더 공식 가격으로 범위만 낸다.

## 1. 측정 (스냅숏 `data/raw/20261029/`, `scripts/token_estimate.py`)

추출 입력 규칙은 부록 B1(판례: 판시사항 + 판결요지, 없으면 본문 앞 6천 자, 참조조문 제외 · 해석례: 질의요지 · 회답 · 이유 · 심판: 주문 · 청구취지 · 이유 앞 6천 자).

| 대상 | 문서 | 추출 입력(자) | 문서당 평균 | Qwen3 토큰(참고) | 전문(자) |
|---|---|---|---|---|---|
| 판례(법원) | 1,401 | 2,990,529 | 2,134 | 2,141,811 | 15,632,993 |
| 해석례 | 276 | 1,099,552 | 3,983 | 755,644 | 1,141,220 |
| 심판 | 1,523 | 6,843,740 | 4,493 | 4,909,133 | 10,321,929 |
| 합 | 3,200 | **10,933,821** | | **7,806,588** | 27,096,142 |

- Qwen3 토크나이저로 0.71토큰/자. 벤더 토크나이저는 다르므로 플랜대로 **1자 ≈ 1토큰(보수)**을 상한, 0.71을 하한 참고로 쓴다
- 평가 원천(T3 dev · test 묶음 약 230건)은 추출에서 빠지므로 실제는 조금 작다(판례 평균 2,134자 × 230 ≈ 0.5M자)
- 플랜 추정(판시사항 우선 10~15M, 전문 40~45M)과 비교: 우선 입력 10.9M자로 범위 안, 전문은 27M자로 추정보다 작다

## 2. 작업별 토큰

| 작업 | 입력 | 출력 | 근거 |
|---|---|---|---|

## 3. 가격대별 총비용 (USD, 표준 요금, 배치 할인 전)

| 가격대(입력/출력 $/1M) | 해당 모델 예 | 출력 3.1M | 출력 6M(생각 포함 상한) |
|---|---|---|---|
| 10 / 50 | Claude Fable 5.1, GPT-6 Astra | 약 355 | 약 500 |
| 4 / 20 | Claude Opus 5.5, Gemini 4 Argon(12월부터) | 약 140 | 약 200 |
| 2 / 10 | Claude Sonnet 5.5, GPT-6.1 Sol, Gemini 4 Argon(11월까지) | 약 70 | 약 100 |
| 1 / 5 | GPT-6.1 Terra | 약 35 | 약 50 |
| 0.75 / 3.75 | Gemini 3.8 Flash(12월까지 도입가) | 약 27 | 약 38 |
| 0.10 / 0.50 | Claude Haiku 5.5, GPT-6 Luna | 약 4 | 약 5 |

- **배치 50% 할인:** 세 벤더 모두 배치가 표준의 절반이다. 추출 · 바꿔 쓰기(입력 약 15M)는 배치로 돌릴 수 있어 위 금액에서 약 40% 줄어든다
- **캐시:** 문서마다 같은 지시 · 스키마(약 3.2M)는 캐시 읽기로 크게 준다(Claude Opus 5.5 · Sonnet 5.5 0.05배(11-10 정정, 처음 표기는 약 0.1배), OpenAI 0.05배)
- 결론: 품질 상위 등급(4/20)을 써도 **배치 · 캐시 적용 시 약 100달러 안팎, 생각 토큰을 넉넉히 잡아도 200달러 이하**. 중간 등급(2/10)이면 약 50~100달러

## 4. 예산 상한 제안 (사용자 결정)

- 제안: **상한 200달러**(4/20 등급 + 생각 토큰 상한 기준). 11-10 구어체 추가 뒤에는 **280달러**(5절). **→ 11-10 사용자 결정: 상한 100달러(6절).** 2주차 D1 표본 100건 실측 비용 × 32배가 상한을 넘으면 플랜대로 추출 입력을 판결요지 우선으로 줄이거나 한 등급 낮춘다
- 벤더 선택 전에 남은 확인: **벤더 약관의 "출력물로 모델 학습" 허용 여부**(1주차 D1 항목, 아직 기록 없음. 기한을 11-17로 다시 잡음(11-11~13 권장), PLAN 의존성 표). 바꿔 쓰기 결과는 어댑터 B 학습 데이터가 되므로 허용되지 않으면 플랜대로 바꿔 쓰기를 오픈 가중치 모델 · 템플릿으로 대체한다

## 5. 11-10 추가: 구어체 평가 세트 (PREREG 4-2-1)

| 작업 | 입력 | 출력 | 근거 |
|---|---|---|---|
| 구어체 test 답변 2회(2주차 기준선 · 4주차 최종) × 1,000(공문서 행과 같은 850(T2 음성 · T6 포함) + 거절 150) | 약 5.9M | 약 0.55M | 2절 답변 행과 같은 문항당 토큰. T2 음성 50 · T6 50은 11-10 3차 검토로 더함(약 +0.6M) |
| 구어체 바꿔 쓰기 1,150건(test 1,000 + dev 150) × 최대 2회(재시도) | 약 1.2M | 약 0.4M | 문항당 지시 포함 약 500토큰 · 출력 약 150토큰 가정. 답변 · 학습과 다른 벤더 |
| **새 합** | **약 27.1M**(2절 약 20M) | **약 4M**(생각 포함 상한 약 8M) | |

- 4/20 등급 표준 요금: 약 140 → **약 195달러**, 생각 토큰 상한이면 약 200 → **약 275달러**(배치 · 캐시 전). 배치 · 캐시를 쓰면 약 130달러 안팎
- 2/10 등급: 약 70 → 약 95달러, 상한 약 100 → 약 135달러
- 바꿔 쓰기는 다른 벤더라 그 벤더 비용은 수 달러 수준이다(위 1.2M · 0.4M을 그 벤더 가격으로 계산)
- **예산 상한 제안을 200 → 280달러로 바꾼다**(4절과 같은 기준: 4/20 등급 + 생각 토큰 상한, 배치 전). 사용자 결정. **→ 11-10 사용자 결정은 100달러(6절)**

### 약관: 출력물로 모델 학습 (학습 바꿔 쓰기 교사 선택에 걸림)

- **OpenAI:** 이용약관 금지 항목에 "출력물로 OpenAI와 경쟁하는 모델 개발"이 있다. 4B Text2Cypher 어댑터 학습이 여기에 걸리는지는 공식 해석이 없다(Citations 7).
- **Google(Gemini API 추가 약관):** "서비스와 경쟁하는 모델 개발에 서비스를 쓰지 말 것" 조항이 있다(보관본 기준, 현행 문구는 미확인, Citations 8).
- **DeepSeek(오픈 플랫폼 약관, 2026-04-22 공개 · 04-29 시행):** 4.2(3)에서 입력 · 출력을 "다른 모델 학습(모델 증류 등)"에 쓸 수 있다고 명시하고, 경쟁 모델 금지 조항은 없다. 이 약관이 끌어오는 별도 이용약관은 읽지 않았다(Citations 9).
- 그래서 **학습 교사는 약관이 학습을 명시적으로 허용하는 DeepSeek로 둔다.** 추출 결과는 그래프 엣지로만 쓰고 모델 학습에 쓰지 않으므로 이 문제와 관계없다.
- 이 판단은 약관 문구를 읽은 결과이고 법률 자문이 아니다. 최종 확인은 사용자가 한다(기한 11-17).

  - **구어체 바꿔 쓰기를 Gemini 3.8 Flash(66.6점)에서 Gemini 4 Argon(81.6점)으로 바꾼다.** 구어체 세트는 바꿔 쓰기 품질이 곧 평가의 타당성이고, 오류가 5%를 넘으면 재생성 · 재검수, 사전 밖 이름 확인이 늘어난다. 차이는 약 +2달러다. 생성 · 재생성은 모두 11-24 동결 전이라 12-01 가격 인상과 관계없다.
  - **학습 교사를 GPT-6.1 Terra에서 DeepSeek Flash로 바꾼다.** 약관이 학습을 명시적으로 허용하는 쪽이다. 비용도 약 3에서 약 0.8달러로 준다. 점수(65)가 낮은 영향은 어댑터 B(핵심 성과 1)로 바로 가는데, 3주차 D2 슬롯 보존 검사 · 표본 100은 슬롯만 보고 자연스러움 · 다양성은 보지 않는다. 그래서 **11-26에 약 50건을 먼저 시험 생성하고, 미리 적은 전환 기준(PLAN 부록 5, `docs/finetune-data.md`로 11-24 잠금)으로 계속 쓸지 정한다.**
- **벤더 분리(PREREG 4-2-1 "모두 다른 벤더"):** 구어체 바꿔 쓰기는 Google, API 천장은 OpenAI, 학습 교사는 DeepSeek, 평가 모델은 Qwen이라 모두 다르다.
  - 학습 교사를 바꿔야 할 때 대안은 Google(Gemma 포함) · Qwen이면 안 된다(구어체 바꿔 쓰기 · 평가 모델과 겹침).
  - 구어체 바꿔 쓰기 키가 늦어 로컬 오픈 가중치 대안을 쓸 때도 OpenAI · DeepSeek · Qwen 계열은 안 된다(천장 · 교사 · 평가 모델과 겹침).
- B는 천장을 점수가 가장 높은 모델로 두고 싶을 때다. 상한 안에 들지만 여유가 약 34달러로 준다.
- 확인할 것(11-18 dev): Gemini 4 Argon의 temperature 0 지원 · 권장값. PREREG 4-2-1은 "temperature 0 또는 벤더 최저값"이라 그대로 쓰되, dev에서 반복 · 잘림이 보이면 기록한다.
- **Argon 생각 토큰:** 출력 가격에 생각 토큰이 들어간다. Argon은 생각을 끌 수 없고(`thinking_level` low · medium · high, 기본 medium, `minimal`은 400 오류), 가장 낮은 `low`로 둔다. 바꿔 쓰기 출력은 약 150토큰인데 생각이 문항당 약 1천 토큰이면 2,300회 호출에 약 11.5달러(배치)라 Google 한도 10달러를 넘는다. 그래서 11-18 dev에서 문항당 실제 토큰(생각 포함)을 재고, 아래 "실행 전 한도 확인"을 한다.

### 지출 한도와 기록

- 콘솔 한도는 벤더마다, 달마다 걸리고 이 작업은 세 벤더 · 11월 · 12월에 걸친다. 벤더마다 100달러로 걸면 실제 상한이 수백 달러가 된다. 그래서 **전체 100달러를 벤더별로 나눠 건다.**

| 벤더 | 처음 한도 · 충전 | 예상(기본 / 최악) | 방법 |
|---|---|---|---|
| OpenAI | 50달러 | 약 27 / 약 45(생각 토큰 상한 + 마지막 날 표준 요금) | 조직 · 프로젝트 하드 한도(넘으면 429), 또는 선불 크레딧 |
| Google | 10달러 | 약 3 / 약 5(생각 토큰은 11-18 dev 실측 뒤 다시 계산) | AI Studio 프로젝트 지출 상한(적용에 지연이 있음), 또는 선불 잔액 |
| DeepSeek | 5달러 | 약 0.8 / 약 1.4 | 선불 충전 |
| **예비** | **35달러(충전 · 배정하지 않음)** | – | 실행 전 한도 확인에서 모자란 벤더에만 충전하거나 한도를 올림 |

- **예비를 두는 이유:** 선불로 충전한 돈은 다른 벤더로 옮길 수 없다. 그래서 처음에는 위 값만 충전 · 설정하고, 나머지 35달러는 어디에도 넣지 않고 둔다. 이렇게 해야 "모자란 벤더에 더 쓴다"가 실제로 되고, 모두 합쳐 100달러를 넘지 않는다.
- 두 플랫폼 모두 한도 적용에 지연이 있어 조금 넘을 수 있다. 그래서 한도는 안전장치로만 보고, **누적 지출은 이 문서 아래 "지출 기록"에 실행마다 적는다**(날짜 · 벤더 · 작업 · 금액 · 누적).
- **실행 전 한도 확인(한 번만 돌리는 실행):** 다음 실행 전에 그 벤더의 남은 한도가 **실행 추정치의 2배 이상**인지 확인한다. 추정치는 dev 실측 문항당 비용 × 문항 수 × 최대 생성 횟수다. 모자라면 **예비 35달러에서 그 벤더에 더 충전하거나 한도를 올리고**, 전체 100달러는 그대로 둔다. 배정 내역은 지출 기록에 적는다.
  - 11-19 구어체 T1 · T3 · 거절 test 생성, Text2Cypher 구어체 test 생성(Google)
  - 11-23까지(조건부) 오류율 5% 초과 묶음의 구어체 재생성(Google, PREREG 4-2-1)
  - 11-25 2주차 기준선 API 답변(OpenAI)
  - 11-26 학습 바꿔 쓰기(DeepSeek)
  - 12-08 최종 API 답변(OpenAI)
- 그래도 한도 · 네트워크 오류로 중간에 끊기면, 끊긴 문항부터 같은 프롬프트 · 설정으로 이어서 돌리고 기록한다(PREREG 4-2-1. 결과를 보고 다시 돌리는 것이 아님). 평가 답변 실행의 오류 · 만료 · 벤더 정책 거절은 PREREG 4-5 "실행 실패 · 벤더 정책 거절 처리"를 따른다(같은 요청 최대 2회 재시도, API 쪽 남은 실패는 짝에서 양쪽 제외).
