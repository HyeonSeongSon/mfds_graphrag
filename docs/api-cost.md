# 벤더 API 비용 메모 (1주차 D3, 2026-10-29)

플랜 1주차 D3 5번 "문서 유형별 평균 길이 → API 토큰 추정 → (사용자) 예산 상한"의 산출물이다. 2주차 D1에 표본 100건으로 실제 비용을 다시 잰다. 벤더는 아직 정하지 않았으므로 대표 벤더 공식 가격으로 범위만 낸다.

## 1. 측정 (스냅숏 `data/raw/20261029/`, `scripts/token_estimate.py`)

추출 입력 규칙은 부록 B1(판례: 판시사항 + 판결요지, 없으면 본문 앞 6천 자, 참조조문 제외 · 해석례: 질의요지 · 회답 · 이유 · 심판: 주문 · 청구취지 · 이유 앞 6천 자).

| 대상 | 문서 | 추출 입력(자) | 문서당 평균 | Qwen3 토큰(참고) | 전문(자) |
|---|---|---|---|---|---|
| 판례(법원) | 1,401 | 2,990,529 | 2,134 | 2,141,811 | 15,632,993 |
| 해석례 | 276 | 1,099,552 | 3,983 | 755,644 | 1,141,220 |
| 심판 | 1,523 | 6,843,740 | 4,493 | 4,909,133 | 10,321,929 |
| 합 | 3,200 | **10,933,821** | | **7,806,588** | 27,096,142 |

- Qwen3 토크나이저로 0.71토큰/자. 벤더 토크나이저는 다르므로 플랜대로 **1자 ≈ 1토큰(보수)**을 상한, 0.71을 하한 참고로 쓴다
- 평가 원천(T3 dev · test 묶음 약 230건)은 추출에서 빠지므로 실제는 조금 작다(판례 평균 2,134자 × 230 ≈ 0.5M자)
- 플랜 추정(판시사항 우선 10~15M, 전문 40~45M)과 비교: 우선 입력 10.9M자로 범위 안, 전문은 27M자로 추정보다 작다

## 2. 작업별 토큰

| 작업 | 입력 | 출력 | 근거 |
|---|---|---|---|
| 비정형 추출 3,200건 | 10.9M(본문) + 3.2M(문서당 지시 · 스키마 약 1천 토큰, 캐시 가능) = **약 14M** | 문서당 약 500 → **약 1.6M** | 측정 + 가정 |
| 바꿔 쓰기 5천 건 | 약 1M | 약 1M | 플랜 추정 |
| test 답변 2회 × 850 | 약 5M | 약 0.5M | 플랜 추정 |
| **합** | **약 20M** | **약 3.1M**(생각 토큰 포함 상한은 2배로 약 6M) | |

추론형 모델은 생각(thinking) 토큰이 출력으로 과금된다. 추출 · 바꿔 쓰기는 낮은 effort로 돌리고, 상한 계산에서는 출력을 2배로 잡는다.

## 3. 가격대별 총비용 (USD, 표준 요금, 배치 할인 전)

| 가격대(입력/출력 $/1M) | 해당 모델 예 | 출력 3.1M | 출력 6M(생각 포함 상한) |
|---|---|---|---|
| 10 / 50 | Claude Fable 5.1, GPT-6 Astra | 약 355 | 약 500 |
| 4 / 20 | Claude Opus 5.5, Gemini 4 Argon(12월부터) | 약 140 | 약 200 |
| 2 / 10 | Claude Sonnet 5.5, GPT-6.1 Sol, Gemini 4 Argon(11월까지) | 약 70 | 약 100 |
| 1 / 5 | GPT-6.1 Terra | 약 35 | 약 50 |
| 0.75 / 3.75 | Gemini 3.8 Flash(12월까지 도입가) | 약 27 | 약 38 |
| 0.10 / 0.50 | Claude Haiku 5.5, GPT-6 Luna | 약 4 | 약 5 |

- **배치 50% 할인:** 세 벤더 모두 배치가 표준의 절반이다. 추출 · 바꿔 쓰기(입력 약 15M)는 배치로 돌릴 수 있어 위 금액에서 약 40% 줄어든다
- **캐시:** 문서마다 같은 지시 · 스키마(약 3.2M)는 캐시 읽기로 크게 준다(Claude 약 0.1배, OpenAI 0.05배)
- 결론: 품질 상위 등급(4/20)을 써도 **배치 · 캐시 적용 시 약 100달러 안팎, 생각 토큰을 넉넉히 잡아도 200달러 이하**. 중간 등급(2/10)이면 약 50~100달러

## 4. 예산 상한 제안 (사용자 결정)

- 제안: **상한 200달러**(4/20 등급 + 생각 토큰 상한 기준). 2주차 D1 표본 100건 실측 비용 × 32배가 상한을 넘으면 플랜대로 추출 입력을 판결요지 우선으로 줄이거나 한 등급 낮춘다
- 벤더 선택 전에 남은 확인: **벤더 약관의 "출력물로 모델 학습" 허용 여부**(1주차 D1 항목, 아직 기록 없음). 바꿔 쓰기 결과는 어댑터 B 학습 데이터가 되므로 허용되지 않으면 플랜대로 바꿔 쓰기를 오픈 가중치 모델 · 템플릿으로 대체한다
