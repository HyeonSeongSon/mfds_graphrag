## 3단비교 (T4 분기)

- `target=thdCmp&knd=2`(위임조문 3단비교) 응답에 **조문 단위 위임이 있다.** `법률조문` 아래 `시행령조문` · `시행규칙조문`이 위임받은 조문(법령명 · 조번호 · 조제목)을 담는다
- 약사법: 법률 조문 557개 중 145개에서 위임 연결 505개
- **T4 분기는 발동하지 않는다.** M1 · M2 정답은 3단비교에서 자동 생성
- 주의: 위임 대상에 식약처 소관이 아닌 법령이 섞인다(약사법 시행규칙 = 보건복지부령 96건, 동물용 의약품등 취급규칙 71건 등). 그래프 · 문항에는 대상이 식약처 87개 법령인 연결만 쓴다
- 약사법의 식약처 소관 총리령은 「의약품 등의 안전에 관한 규칙」이다(이름에 "약사법 시행규칙"이 없음)

## DUR (병용금기 고시 별표)

- 고시: 「의약품 병용금기 성분 등의 지정에 관한 규정」, 시행 2026-07-21. 별표 1 병용금기 · 별표 2 특정연령대 금기 · 별표 3 임부금기
- 별표는 상자 그림 문자(┌│├) 표. 행 경계 `├`, 칸 `│`, 여러 줄 칸은 이어 붙여 파싱
- 행 수: 별표 1 **1,680** · 별표 2 **211** · 별표 3 **1,240**, 세 별표 모두 연번 누락 0
- **성분명은 영문**이고 대소문자가 섞인다(`acemetacin` · `Vonoprazan`). 괄호 주석이 붙는다: 제형(`(경구제)` · `(질내삽입링)`), 분류번호(`(분류번호 : 421)`), 동의어(`valproic acid(valproate)`). 복합제 130개(`A + B`), `~ 함유제제` 표기 있음. 별표 1 서로 다른 성분 표기 763개
- 의약품안전나라 같은 유형 건수와 대조: 병용 1,680 vs 1,762(−4.7%), 연령 211 vs 230(−8.3%), 임부 1,240 vs 1,439(−13.8%). 고시 연번이 연속이라 파싱 누락은 아니다. 의약품안전나라는 같은 쌍을 여러 행으로 나누거나 고시 뒤에 추가된 항목이 있을 수 있어 1:1 대응이 아니다

### 같은 업소 처분 검토 (2026-10-28)

질문: 인허가번호를 지우면 같은 업소의 처분이 dev · test · 그래프로 갈라져 누수가 생기는가. I0470 5,417건을 원본에서 집계했다(값은 출력하지 않음).

- **위반 문구 앞에 `(YYYYMMDD)` 날짜가 붙는다.** 플랜의 날짜 제거 규칙이 이 형식을 놓치면 정확 일치 묶음이 2,700개로 갈라지고, 이 형식까지 지우면 **923개**로 합쳐진다. 정규화 규칙에 `(YYYYMMDD)` 제거를 반드시 넣는다(빠지면 같은 위반이 dev · test · 그래프에 흩어지는 큰 누수)
- 날짜를 지운 뒤 묶음 크기: 1건 641 · 2~5건 181 · 6~20건 70 · 21~50건 15 · 50건 초과 16개. **50건 초과 묶음 16개에 3,051행(56%)**이 몰려 있다. 표본 조건(이웃 포함 50건 이하)을 만족하는 묶음은 약 907개라 T1 230문항(후보 460 이상)은 가능해 보이지만, 흔한 위반이 문항에서 빠지는 치우침이 크다(한계로 기록, 수치는 D4 dry-run에서 근접 중복을 합쳐 다시 셈)
- **인허가번호는 업소 식별자로 부족하다.** 인허가번호가 같은 처분은 37곳 74건뿐이다. 업소명 + 주소로 묶으면 122곳 251건이고, 이 가운데 87곳은 인허가번호가 둘 이상이다(업종 · 재등록마다 번호가 다름)
- 같은 업소(업소명 + 주소) 처분 쌍 138개 중 85개는 정확 일치 묶음에 이미 들어가고, 53개는 텍스트 규칙(정확 일치 · 5-gram Jaccard 0.8)을 빠져나간다. 빠져나간 쌍은 대부분 같은 날 같은 사건을 다른 문구로 적은 것이다(예: "시설물 멸실" ↔ "법 제27조제3항제1호를 위반하여 …")
- 빠져나가면서 근거 조문까지 같은 처분은 **44건(0.8%)**이다. T1 test 200 · dev 30을 뽑으면 기대 영향은 2문항 안팎이다. 작지만 0이 아니다

**해결:** 업소 키를 파일로 남기지 않고, `build_evalset.py`가 git 제외 원본 스냅숏을 읽을 때 메모리에서만 업소명 + 주소(공백 제거)로 키를 만들어 **별 모양 근접 중복 검사에 이웃 조건으로 추가**한다. 즉 문항마다 "같은 업소의 다른 처분"을 제외 목록에 넣고, 이웃 수(50건 이하 조건)에도 센다. 묶음끼리 잇지 않으므로 연쇄가 생기지 않는다. dev 문항과 test 문항이 같은 업소면 dev 문항을 버리고 다음 후보를 뽑는다(근접 중복과 같은 규칙). 결과물에는 처분 ID만 남고, 그래프 · 가공 데이터 · 고정 자료에는 업소 정보가 들어가지 않는다. 묶음 함수 테스트는 가짜 업소명으로 만든 합성 자료로 한다

## 플랜에 반영할 것

1. 성분 uid는 "정규화한 한글 대표명"이 아니라 **정규화한 영문명**(소문자, 공백 정리). 괄호 안 제형은 DurRule의 조건 속성으로, 동의어는 `aliases`로, 분류번호는 속성으로 분리. 복합제 · 함유제제 처리 규칙은 D2 `ingredients.py`에서 정한다
2. DUR 파싱 검증 기준을 "의약품안전나라와 2% 이내"에서 **"고시 연번 연속 · 누락 0"**으로 바꾸고, 의약품안전나라 차이는 사유 표본과 함께 참고로 보고
3. 3단비교 위임 연결은 대상 법령이 식약처 87개 안일 때만 그래프 · 문항에 쓴다
4. 식품 처분 건수 기준을 9,065 → 고유 5,417로 바꾼다(manifest 대조, T1 표본 가능 문항 460 확인, 제외 목록 30% 기준의 분모). `collect/foodsafety.py`는 I0470만 받는다
5. PREREG 4-4: T1 위반 문구 정규화에 `(YYYYMMDD)` 제거를 명시하고, 근접 중복 별 모양 검사에 "같은 업소(업소명 + 주소, 원본에서 메모리로만)" 이웃 조건을 더한다. 50건 초과 묶음에 처분 56%가 몰린다는 점을 T1 한계로 적는다
