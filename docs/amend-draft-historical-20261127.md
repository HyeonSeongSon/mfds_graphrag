## 기록 절차

셸을 거치지 않게 Python 스크립트로 기록한다. 스크립트는 블록을 목록 인자로 `eval/prereg.py amend`에 넘긴다. 블록의 큰따옴표는 PREREG 원문 표기와 같은 ASCII 따옴표 그대로 둔다.

```powershell
conda activate mfds-graphrag
python C:\Users\kikki\AppData\Local\Temp\claude\22c8d26e9b18a1ad\bcbdb5d9-8bc8-4e88-b20c-ce27b9369bfb\scratchpad\verify_amend.py before
python C:\Users\kikki\AppData\Local\Temp\claude\22c8d26e9b18a1ad\bcbdb5d9-8bc8-4e88-b20c-ce27b9369bfb\scratchpad\record_amend.py
python C:\Users\kikki\AppData\Local\Temp\claude\22c8d26e9b18a1ad\bcbdb5d9-8bc8-4e88-b20c-ce27b9369bfb\scratchpad\verify_amend.py after
```

1. **`before`:** 다음 네 가지를 출력하고, 비교용으로 저장한다.
   - `prereg.py check`의 exit 코드와 상태 집계
   - AMENDMENTS 항목 수
   - 블록의 sha256
   - 블록이 한 줄인지
2. **`record_amend.py`:** 블록을 다시 읽어 한 줄인지 단언한다. 그다음 `python eval/prereg.py amend --kind rule --content <블록>`을 저장소 루트에서 실행하고(`check=True`), 새 항목의 id와 시각을 출력한다.
3. **`after`:** 다음 세 가지가 모두 맞아야 통과다.
   - 항목 수가 하나 늘었다.
   - 마지막 항목의 content sha256이 블록 sha256과 같다.
   - check 결과(exit와 상태 집계)가 `before`와 같다. 이번 항목은 파일을 바꾸지 않으므로 같아야 한다.
4. **기록을 마치면** 이 파일 첫머리 제목 아래에 "기록됨: 항목 id · 시각"을 적는다. 검증은 블록 해시만 보므로 이 줄은 영향이 없다.

계획 시점(2026-11-27)의 check는 exit 0, 28개 모두 "기준과 같음"이다.

## 항목 5 알려진 한계 (기록 문구에는 넣지 않음)

- **regex의 잘못된 엣지:** "구" 표기가 붙은 것 중 1개다(case:221915). 원문 표기가 식약처 사전에 없는 시행령 · 시행규칙 이름으로 시작하는 참조도 이 1개뿐이다. 같은 꼴은 "구"가 없어도 잘못 읽힌다(조각 시험). 다른 꼴은 세지 않았다. refs.py가 잠겨 있어서 고치지 않는다.
- **해석례 · 심판의 같은 꼴: 미측정.** 출현 문서는 해석례 11 · 심판 70이고, 약칭 괄호 꼴은 두 정규식으로 0이다. LLM 추출 항목에서 오독되는지는 적재 보고에서 센다.
  - 적재 보고에 더할 셈: 약사법 조문으로 해석됐는데 항목 text에 "시행규칙"이 들어 있는 추출 참조 수
- **regex에서 첫 인용이 구법일 때:** 뒤의 현행 인용이 사라진다(uid 7개).
- **extracted의 항목 안 OR:** `extract.py`는 한 항목 안에서 자리 중 하나라도 구법이면 그 조문을 표시한다. AND는 항목 사이에서만 걸린다.

## 항목 6 테스트 (적재 코드)

- regex 엣지는 근거 (1) · (4)만 받고, (2) · (3)은 받지 않는다.
- field 엣지는 대상이 아니다(refs.py 표시만).
- (4)는 공포일 표에 없는 법령과 날짜가 빈 문서에 쓰지 않는다. 약사법 시행규칙 행은 적용되는 조문이 없다.
- 근거별 건수를 겹침까지 포함해 센다. (3)은 붙여 쓴 "구「"와 띄운 "구"로 나눠 센다.
- extracted에서 같은 문서 · 같은 조문을 인용한 항목 둘 중 하나만 구법이면 `false`다.
- regex에서 같은 uid는 첫 인용 표시를 따른다.
- 서로 다른 uid가 호 → 항(없는 항 → 조)으로 올라가 합쳐지면 AND다.
- INTERPRETS · APPLIES도 같은 근거와 합치기 규칙을 따른다.
