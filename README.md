# mfds-graphrag

GPU 6GB(RTX 2060) 한 장으로 온프레미스에서 서빙하는 식약처 소관 규제 Graph RAG.

- 데이터: 식약처 소관 법령 87 · 행정규칙 513 · 판례 · 해석례 · 행정심판 · 식품/의약품 행정처분 · DUR(병용금기 고시 별표)
- 그래프: Neo4j 5.26 Community, 노드 약 5만
- 모델: Qwen3 4B(양자화 GGUF, llama.cpp) + Text2Cypher LoRA 어댑터, 기준선 8B · 벤더 API
- 평가: 사전 등록(`eval/PREREG.md`), 평가 원천은 그래프 적재 단계에서 제외

전체 계획은 [docs/PLAN.md](docs/PLAN.md). 1주차 진행 중이며, 실행 방법은 구현이 끝나는 대로 채운다.

## 온프레미스 전제

외부로 나가도 되는 것은 공개 법령 · 판례 · 처분 데이터뿐이다. 벤더 API는 공개 데이터의 추출과 오프라인 평가에만 쓰고, 사내 문서 적재와 최종 답변은 로컬에서 처리한다.
